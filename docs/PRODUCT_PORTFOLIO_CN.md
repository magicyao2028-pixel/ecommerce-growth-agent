# 中文项目说明：电商增长分析 Agent

## 项目定位

本项目面向中小电商企业，将店铺流量、订单、广告和库存数据统一整理为可审核的经营诊断与行动建议。公开作品集版本使用合成数据，不包含任何公司、客户或消费者隐私。

## 解决的问题

- 多张表格重复统计，经营分析耗时；
- 不同运营人员判断标准不一致；
- 问题发现后缺少证据、负责人和优先级；
- 直接让大模型计算指标容易产生不可追溯错误；
- 自动调整广告、价格或库存存在经营风险。

## 产品方案

系统先校验数据，再通过确定性程序计算GMV、点击率、转化率、广告ROI和贡献利润，然后按SKU识别流量、转化、投放及库存风险。每条建议必须展示指标证据，并由人工确认后才能执行。

## 个人能力证明

该仓库完整包含：

- 用户和业务问题分析；
- 产品需求文档PRD；
- 业务流程与责任划分；
- 系统架构和接口规范；
- Python离线分析程序；
- 免费网页交互原型；
- 自动化测试；
- Agent评测方案；
- 安全、权限和人工审批边界；
- 后续版本路线图。

## 真实边界

当前版本是产品验证MVP，不宣称已经提升真实GMV或节省实际人力。经营阈值属于待验证假设；只有经过真实用户试用、基线对比和结果复盘后，才能写入业务成果。
